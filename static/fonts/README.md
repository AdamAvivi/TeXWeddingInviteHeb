# Bundled fonts

Font binaries are copied without modification. Keep this directory's notices and licenses when redistributing the project.

| Selector | File | Source and license |
| --- | --- | --- |
| SBL Hebrew | `SBL_Hbrw.ttf` | [SBL font information](https://www.sbl-site.org/resources/fonts-faq/); `licenses/SBL-license.pdf`. Free non-commercial use; commercial use requires a separate license. |
| Keter YG | `KeterYG-Medium.ttf` | [Open Siddur](https://opensiddur.org/wp-content/uploads/fonts/KeterYG/KeterYG.zip); GPL v2 with font exception, notices in `licenses/KeterYG/`. |
| Shlomo | `Shlomo.ttf` | [Open Siddur](https://opensiddur.org/wp-content/uploads/fonts/Shlomo/Shlomo.zip); [author's OFL statement](https://github.com/avimar/fonts-hebrew/blob/master/Fonts/Hebrew%20Letters%20with%20Vowels%20and%20Cantillation/Shlomo%20Orbach%20%28OFL%29/README.htm) preserved in `licenses/Shlomo-OFL.txt`. Original font metadata is retained in `licenses/Shlomo-NOTICES.txt`; some metadata still names Ezra SIL SR. |
| Shofar | `ShofarRegular.ttf` | [Open Siddur](https://opensiddur.org/wp-content/uploads/fonts/Shofar/Shofar.zip); GPL v2 with font exception, notices in `licenses/Shofar/`. |
| Dyslexia Hebrew | `DyslexiaHebrew-Regular.otf` | [Open Siddur](https://opensiddur.org/wp-content/uploads/fonts/DyslexiaHebrew/DyslexiaHebrew.zip); SIL OFL 1.1 in `licenses/DyslexiaHebrew/`. Listed upstream as DyslexiaHebrew (Extended), by Jake Shoag. |
| Dorian CLM | `DorianCLM-Book.ttf` | [Open Siddur](https://opensiddur.org/wp-content/uploads/fonts/DorianCLM/DorianCLM.zip); GPL v2, notices in `licenses/DorianCLM/`. |
| Ktav Yad CLM | `KtavYadCLM-MediumItalic.ttf` | [Open Siddur](https://opensiddur.org/wp-content/uploads/fonts/KtavYadCLM/KtavYadCLM.zip); GPL v2, notices and supplied Type 1 sources in `licenses/KtavYadCLM/`. This is the original handwritten italic face. |
| Nachlaot | `Nachlaot.ttf` | [Open Siddur](https://opensiddur.org/wp-content/uploads/fonts/Nachlaot/Nachlaot.zip); GPL with font exception as explained in the upstream pack's `licenses/OpenSiddur-LICENSES.txt` (Refoyl Finkl's permission). Original font notice in `licenses/Nachlaot-NOTICES.txt`. |
| DejaVu Sans | `DejaVuSans.ttf` | Original DejaVu notices in `LICENSE.txt`. Also used for English and punctuation absent from Hebrew-only fonts. |

The fonts and documentation are distributed upstream in the [Open Siddur font pack](https://github.com/avimar/fonts-hebrew). Culmus fonts and source releases are available from the [Culmus project](https://culmus.sourceforge.io/). Font licenses apply to these assets independently of the application's license.

Ktav Yad CLM and Nachlaot do not support all Hebrew vowel marks. Select another font for text that needs full niqqud support. The original invitation template is not modified to add the font choices.
